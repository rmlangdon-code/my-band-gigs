# My Band Gigs

Shared calendar for gigs, rehearsals, and availability.

## Render Web Service

- Runtime: Node
- Build: `npm install`
- Start: `node server.js`

Environment:

- `DATABASE_URL` — Internal Postgres URL
- `JWT_SECRET` — long random string
- `NODE_ENV` — `production`

First account that signs up becomes admin of THoRR and Retro Revolution.
Invite others from the Members card (copies a link).
