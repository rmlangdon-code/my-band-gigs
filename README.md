# My Band Gigs

Phone-first band calendar (demo).

This first Render deploy is the look-and-feel app. Each browser still keeps its own data. Shared logins and one calendar for the whole band come in the next deploy.

## Render (static site)

1. Put this folder in a GitHub repository.
2. In Render: New + → Static Site.
3. Connect GitHub and pick this repo.
4. Build command: leave blank.
5. Publish directory: `.` (the folder that contains index.html).
6. Create Static Site.

You will get a URL like `https://my-band-gigs.onrender.com`.
